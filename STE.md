# STE writing rules for this course

Write all learner text to ASD-STE100.

## Length

- Procedure sentence: 20 words or fewer.
- Description sentence: 25 words or fewer.
- One topic in each sentence.

## Voice and verbs

- Procedures use the imperative: "Open the project."
- Descriptions use the simple present: "A flag is a complaint."
- Use the active voice.
- Do not use slang. Do not use idioms.

## Words

- Use one meaning for each word.
- Keep project names as they are: flag, rollout, axis, grounded, Labelbox.
- Do not invent a new name for a project idea.

## Feedback text

- Correct: "Correct."
- Not correct: "Not correct." Then give the rule.
- Do not write cheer text. Do not write jokes.

## Checks

Count the words in each new sentence. Read the sentence aloud. If a person new to the task cannot act, rewrite.
